# &lt;Byteon AR /&gt; — Portafolio Personal

Sitio web de portafolio personal de la marca **Byteon Argentina**, desarrollado por **Thomás Lesta**.  
Diseño profesional, responsive y bilingüe (español / inglés), construido con HTML, CSS y JavaScript puro.

## 📁 Estructura del proyecto

```
byteon-argentina/
├── index.html          → Inicio
├── quiensoy.html       → Quién Soy
├── proyectos.html      → Proyectos
├── actualidad.html     → Actualidad tech (GNews API)
├── redes.html          → Redes sociales
```

---

## ✨ Características

- 🎨 **Diseño negro / amarillo / blanco** — paleta de marca Byteon Argentina
- 📱 **Responsive** — adaptado para mobile, tablet y desktop
- 🌍 **Bilingüe** — cambio español / inglés con banderas 🇦🇷 🇺🇸, persistido en `localStorage`
- 🤖 **Actualidad con IA** — noticias reales vía GNews API, resumidas automáticamente por Claude AI en el idioma del usuario
- ⚡ **Animaciones** — scroll reveal con Intersection Observer, skeleton loaders, ticker de tecnologías
- 🧭 **Navbar fija** con hamburger menu en mobile
- 📬 **Formulario de contacto** — abre el cliente de correo con los datos pre-completados
